StreamView Analytics — Proyecto Visual Analytics

Solución de Visual Analytics desarrollada como proyecto semestral, donde el equipo asume el rol de consultora externa para StreamView Analytics, una plataforma de streaming en Latinoamérica.

🎯 Objetivo

Transformar el catálogo audiovisual (películas y series) en información accionable mediante dashboards interactivos, KPIs y narrativas visuales que apoyen decisiones estratégicas de adquisición, producción y promoción de contenidos.

📊 Datasets
netflix_movies_detailed_up_to_2025 (~16.000 registros)
netflix_tv_shows_detailed_up_to_2025 (~16.000 registros)
🗂️ Etapas del proyecto
Etapa	Entregable
EP1 – Comprensión del negocio	Informe ejecutivo + Storytelling
EP2 – Diseño de dashboards	Dashboard interactivo
EP3 – Evaluación y optimización	Informe de evaluación crítica
EFT – Presentación ejecutiva	Solución integral + Defensa
🛠️ Stack
Limpieza y ETL: Python (pandas)
Visualización: Power BI / Tableau / Excel (según definición del equipo)
